# 💡 Руководство по использованию

## Базовое использование

### Анализ изображения с настройками по умолчанию

```text
Проанализируй изображение: /путь/к/изображению.jpg
```

### Анализ аудио с настройками по умолчанию

```text
Проанализируй аудио: /путь/к/аудио.mp3
```

### Анализ с пользовательским запросом

```text
Проанализируй /путь/к/фото.jpg и опиши эмоции и атмосферу
```

## Продвинутое использование

### Использование системных инструкций

Доступные предустановленные промпты в `config.py`:

- `"default"` - Комплексный анализ
- `"technical"` - Технические детали (разрешение, формат, качество)
- `"creative"` - Художественное и креативное описание

**Пример:**

```json
{
  "image_path": "/путь/к/изображению.jpg",
  "system_instruction_name": "technical"
}
```

### Выбор пользовательской модели

```json
{
  "image_path": "/путь/к/фото.jpg",
  "model_name": "gemini-2.5-pro",
  "user_prompt": "Опиши это изображение детально"
}
```

## Генерация изображений

### Генерация изображения по тексту (text-to-image)

```json
{
  "user_prompt": "Кот в шляпе, стиль пиксель-арт"
}
```

### Генерация изображения по тексту и референсам (text+image(s)-to-image)

```json
{
  "user_prompt": "Создай похожее изображение в стиле киберпанк",
  "image_paths": ["/путь/к/референс1.jpg", "/путь/к/референс2.png"]
}
```

### Генерация с указанием пути сохранения

```json
{
  "user_prompt": "Футуристический город с неоновыми огнями",
  "output_path": "/путь/к/сохранению/изображение.png"
}
```

### Система автоматического бэкапа

Все сгенерированные изображения и аудио автоматически сохраняются в папку `output/`:

**Структура:**

```
output/
├── images/
│   ├── 2025-11-26_16-30-45_футуристический_город.png
│   └── 2025-11-26_16-30-45_футуристический_город.json  # Метаданные
└── audio/
    ├── 2025-11-26_16-32-10_подкаст_интро.wav
    └── 2025-11-26_16-32-10_подкаст_интро.json
```

**Возможности:**

- Имена файлов с временными метками: `YYYY-MM-DD_HH-MM-SS_описание.ext`
- JSON метаданные с параметрами генерации (промпт, модель, настройки)
- Неблокирующий режим (не прерывает генерацию при ошибке backup)

## Анализ GIF-анимаций

### Базовый анализ GIF (рекомендуемые настройки)

Анализируйте UI-туториалы, демонстрации программ или любые анимированные GIF с умной выборкой кадров:

```json
{
  "image_path": "/путь/к/туториалу.gif",
  "prompt": "Это демонстрация функции VS Code. Опиши каждый шаг.",
  "frame_count": 5,
  "quality": "fhd"
}
```

**Настройки по умолчанию:**

- **Режим:** `total` - равномерно распределённые кадры
- **Количество кадров:** 5 (настраивается: 5-15+)
- **Качество:** `fhd` (1920px) - лучшее для читаемости текста
- **Модель:** `gemini-2.5-flash`

### Режимы извлечения кадров

#### 1. Режим Total (Рекомендуется)

Извлечение фиксированного количества равномерно распределённых кадров - идеально для UI-туториалов:

```json
{
  "image_path": "/путь/к/анимации.gif",
  "mode": "total",
  "frame_count": 10,
  "quality": "fhd"
}
```

**Сценарии использования:**

- 5 кадров: Быстрые демо (10-30с)
- 10 кадров: Детальные туториалы (30-90с)
- 15+ кадров: Длинные сессии (2+ мин)

#### 2. Режим FPS

Извлечение кадров с указанной частотой (кадров в секунду):

```json
{
  "image_path": "/путь/к/анимации.gif",
  "mode": "fps",
  "gif_fps": 1.0,
  "quality": "hd"
}
```

**Пример:** `gif_fps: 1.0` = 1 кадр каждую секунду

#### 3. Режим Interval

Извлечение кадров через фиксированные временные интервалы:

```json
{
  "image_path": "/путь/к/длинной_сессии.gif",
  "mode": "interval",
  "interval_sec": 5.0,
  "quality": "balanced"
}
```

**Пример:** `interval_sec: 5.0` = один кадр каждые 5 секунд

### Пресеты качества

Выбирайте качество в зависимости от задачи:

| Пресет | Разрешение | Лучше для | Стоимость токенов |
|--------|------------|-----------|-------------------|
| `fhd` | 1920px | UI-туториалы с текстом (ПО УМОЛЧАНИЮ) | ~1,500/кадр |
| `hd` | 1280px | Обычные анимации | ~1,000/кадр |
| `balanced` | 960px | Экономный вариант | ~800/кадр |
| `economy` | 768px | Минимальное качество | ~600/кадр |
| `uhd` | Оригинал | Максимум деталей | Варьируется |

### Получение рекомендаций

Получите подробные рекомендации и лучшие практики:

```python
get_gif_guidelines()
```

Возвращает детальную информацию о:

- Выборе количества кадров
- Рекомендациях по пресетам качества
- Оценке стоимости
- Рекомендуемых рабочих процессах
- Примерах использования

### Оценка стоимости

**1080p (FHD) кадры:**

- 5 кадров ≈ 7,500 токенов
- 10 кадров ≈ 15,000 токенов

**Balanced (960px) кадры:**

- 10 кадров ≈ 8,000 токенов

**Совет:** Используйте `get_gif_guidelines()` для детальной разбивки стоимости и рекомендаций.

## Поддерживаемые форматы

- **Изображения:** JPEG, PNG, GIF (статичные), WEBP, HEIC, HEIF (Макс. размер: 20 МБ)
- **GIF-анимации:** Анимированные GIF файлы (обрабатываются покадрово)
- **Аудио:** MP3, WAV, AIFF, AAC, OGG, FLAC (Макс. размер: 19.5 МБ)

## Формат ответа

### Ответ анализа изображения

Сервер возвращает структурированный JSON-ответ на основе модели `ImageAnalysisResponse`.

```json
{
  "alt_text": "Краткое, доступное описание изображения.",
  "detailed_analysis": "Комплексный и детальный разбор содержания, контекста и композиции изображения.",
  "summary": "Опциональное краткое резюме анализа."
}
```

### Ответ генерации изображения

```json
{
  "status": "success",
  "image_path": "/полный/путь/к/сгенерированному/изображению.png"
}
```

### Ответ анализа аудио

```json
{
  "title": "Обсуждение встречи",
  "summary": "Краткое резюме содержания аудио",
  "transcription": "Полная транскрипция аудио",
  "participants": ["Иван Иванов", "Мария Петрова"],
  "hashtags": ["#встреча", "#обсуждение", "#задачи"],
  "action_items": ["Завершить документацию проекта", "Запланировать следующую встречу"],
  "raw_text": "Сырой текстовый ответ от модели"
}
```

## Доступные модели

- `gemini-2.5-flash-lite` - Быстрая и эффективная (по умолчанию)
- `gemini-2.5-flash` - Сбалансированная производительность
- `gemini-2.5-pro` - Наивысшее качество
- `gemini-2.5-flash-image-preview` - Модель для генерации изображений
- `gemini-2.5-flash-preview-tts` - Модель для генерации речи (по умолчанию)
- `gemini-2.5-pro-preview-tts` - Модель для генерации речи премиум-качества

## Генерация аудио

### Получение руководства по генерации

Получить список доступных голосов (30 предустановленных голосов на 24 языках) и примеры YAML структуры:

```python
get_audio_generation_guide()
```

### Генерация речи из YAML сценария

#### Простой пример (один голос)

Создайте YAML сценарий `podcast.yaml`:

```yaml
cast:
  - name: "Ведущий"
    voice: "Kore"

script:
  - speaker: "Ведущий"
    text: "Добро пожаловать в наш подкаст о технологиях!"
  - speaker: "Ведущий"
    text: "Сегодня мы обсудим последние новости в области ИИ."
```

Генерация:

```python
generate_audio_from_yaml(yaml_path="/путь/к/podcast.yaml")
# Результат: output_audio/podcast.wav
```

#### Пример с двумя голосами

```yaml
cast:
  - name: "Дед"
    voice: "Orus"
  - name: "Бабка"
    voice: "Aoede"

style_prompt: "Русская народная сказка, драматичное исполнение"

script:
  - speaker: "Дед"
    text: "Испеки мне, бабка, колобок."
  - speaker: "Бабка"
    text: "Из чего печь? Муки нет."
  - speaker: "Дед"
    text: "Эх, бабка! По коробу поскреби, по сусеку помети."
```

Генерация с пользовательским путем:

```python
generate_audio_from_yaml(
    yaml_path="/путь/к/сказка.yaml",
    model="gemini-2.5-pro-preview-tts",
    output_path="/путь/к/сохранения/колобок.wav"
)
```

### Параметры генерации аудио

| Параметр | Тип | Обязателен | Описание |
|----------|-----|------------|----------|
| `yaml_path` | string | ✅ | Абсолютный путь к YAML файлу со сценарием |
| `model` | string | ❌ | Модель TTS (по умолчанию: gemini-2.5-flash-preview-tts) |
| `output_path` | string | ❌ | Абсолютный путь для сохранения WAV (по умолчанию: output_audio/<имя>.wav) |

### Структура YAML сценария

```yaml
# Необязательное: стилевая инструкция для управления тоном/акцентом
style_prompt: "Спокойный и профессиональный тон, новостной стиль"

# Обязательное: список персонажей
cast:
  - name: "Имя1"    # Имя персонажа
    voice: "Kore"   # Название голоса (регистрозависимое, с большой буквы)
  - name: "Имя2"
    voice: "Orus"

# Обязательное: диалог/текст
script:
  - speaker: "Имя1"
    text: "Первая реплика"
  - speaker: "Имя2"
    text: "Ответная реплика"
```

### Особенности генерации аудио

- **Количество персонажей:** 1-2 (ограничение Gemini API)
- **Голоса:** 30 предустановленных голосов с разными характеристиками
- **Языки:** Автоматическое определение из 24 поддерживаемых языков
- **Формат вывода:** WAV, 24kHz, моно, 16-bit PCM
- **Стилевой промпт:** Опциональная инструкция для управления манерой речи
